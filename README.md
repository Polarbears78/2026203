# 👕 자유복의 날 (육민관중학교)

육민관중학교 **자유복 입는 날**을 저장하고, 다음 날까지 **D-day**로 알려주는 웹앱입니다.
설치 없이 브라우저에서 바로 쓸 수 있고, 모든 데이터는 **내 기기(localStorage)** 에만 저장됩니다.

## 주요 기능

- **앱 설치(PWA)** — 홈 화면에 추가해 주소창 없이 앱처럼 실행, **오프라인 지원**
- **다음 자유복의 날 D-day** 표시
- **달력**에서 자유복 날짜 확인 / 날짜 칸을 눌러 직접 지정·해제
- **월중교육활동 텍스트 붙여넣기 → "자유복" 날짜 자동 추출**
  - 학교 홈페이지의 월중교육활동 글 내용을 복사해 붙여넣으면
    `6월 17일`, `17일`, `6/17`, `30` 같은 표기를 자동으로 인식합니다.
- 날짜 **직접 추가 / 삭제**
- **월중교육활동 바로가기** 링크 + 찾는 방법 안내

## 자유복의 날 확인하는 방법

1. 앱의 **월중교육활동 바로가기** 버튼을 누릅니다.
2. **학교소식 → 월중교육활동**에서 해당 월의 글을 엽니다.
3. 일정에서 **"자유복 입는 날"**을 찾습니다.
4. 그 내용을 복사해 앱의 **"월중교육활동에서 가져오기"** 칸에 붙여넣으면 날짜가 자동 저장됩니다.

> 학교 홈페이지는 외부 자동 접속(스크래핑)을 막아두어, 앱이 자동으로 일정을
> 가져오지는 못합니다. 그래서 **복사·붙여넣기 방식**으로 날짜를 손쉽게 등록하도록 만들었습니다.

## 사용 방법 (로컬 실행)

별도 빌드가 필요 없습니다. 파일을 받은 뒤 `index.html`을 브라우저로 열면 됩니다.

정적 서버로 띄우려면:

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 배포 (GitHub Pages)

이 저장소를 GitHub Pages로 배포하면 모바일에서도 바로 사용할 수 있습니다.

1. GitHub 저장소 **Settings → Pages**
2. **Source: Deploy from a branch** 선택
3. 브랜치를 고르고 폴더는 `/ (root)` 로 지정 후 저장

## 앱으로 설치하기 (PWA)

HTTPS(예: GitHub Pages)로 접속하면 웹 어플리케이션으로 설치할 수 있습니다.

- **안드로이드/크롬**: 접속 후 화면 하단의 **“홈 화면에 앱 추가”** 버튼을 누르거나,
  브라우저 메뉴 → **앱 설치 / 홈 화면에 추가**
- **아이폰(사파리)**: 공유 버튼 → **홈 화면에 추가**

설치하면 주소창 없이 전체화면 앱처럼 열리고, 한 번 연 뒤에는 **오프라인에서도** 동작합니다.

## 파일 구성

- `index.html` — 화면 구조
- `style.css` — 스타일 (모바일 우선)
- `app.js` — D-day 계산, 달력, 텍스트 파싱, 저장, 앱 설치 로직
- `manifest.webmanifest` — PWA 설정(앱 이름·아이콘·테마)
- `sw.js` — 서비스 워커(오프라인 캐시)
- `icon-192.png` · `icon-512.png` · `apple-touch-icon.png` — 앱 아이콘
- `generate-icons.js` — 아이콘 생성 스크립트
